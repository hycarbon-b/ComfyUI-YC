🚀 快速开始步骤：

1️⃣ 重启 ComfyUI
   - 关闭正在运行的 ComfyUI
   - 重新启动 ComfyUI 以加载新插件

2️⃣ 在 ComfyUI UI 中添加节点
   - 点击"添加节点"
   - 导航至: api node > image > OpenAI
   - 选择: OpenAI GPT Image (Custom API)

3️⃣ 配置节点参数
   • prompt: 输入你的图像描述
   • base_url: 保留默认值或改为其他 API 端点
   • api_key: 保留默认值或改为你的 API 密钥
   • model: 选择模型 (gpt-image-1/1.5/2)
   • size: 选择输出尺寸
   • quality: 选择质量等级
   • n: 设置生成图像数量

4️⃣ 运行工作流
   - 点击"生成"或"执行"
   - 等待图像生成完成

  ),
  IO.String.Input(
      "api_key",
      default="sk-yrUpeqcvBYBZpSubF2191...",  # ← 修改此处

🐛 故障排除：

问题: 节点未显示在 ComfyUI 中
解决: 
  1. 确保已重启 ComfyUI
  2. 检查 ComfyUI 的服务器日志
  3. 验证 __init__.py 中的导入语句

问题: API 连接失败
解决:
  1. 验证 base_url 格式是否正确
  2. 检查 api_key 是否有效
  3. 测试网络连接
  4. 查看 ComfyUI 的详细日志

问题: 生成失败 "No images returned"
解决:
  1. 检查 API 账户余额
  2. 确认 model 参数被支持
  3. 验证 API 提供商的限制
